OUTCOMEATLAS WEBSITE - GITHUB PAGES SETUP

Included files:
- index.html : complete website structure and all six sections
- style.css  : responsive design for phones, tablets and computers
- script.js  : section content, detail popups, search and mobile navigation

HOW TO PUBLISH:
1. Download and extract OutcomeAtlas-Website.zip.
2. Open your GitHub repository (the repository used for your current OutcomeAtlas website).
3. Upload index.html, style.css and script.js to the ROOT of the repository.
4. If GitHub asks whether to replace existing files, replace the old index.html and the matching style/script files after keeping a backup if you want the old version.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait a few minutes and open your GitHub Pages website. Refresh the page.

IMPORTANT:
- This is a static website. GitHub Pages can host it, but it does not provide secure user accounts, database storage, private dashboards or server-side login.
- Do not collect passwords or sensitive personal information using this static demo.
- The detail pages explain categories and suggested next steps. Internship and scholarship availability changes; check official provider websites.
- The external resource links in the Learning Resources section are official starting points. Always check their current terms and availability.
